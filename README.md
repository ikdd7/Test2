# 💬 Ripple · 랜덤 1:1 채팅

가입 없이 **버튼 하나로 낯선 사람과 1:1 랜덤 채팅**을 시작하는 서버리스 웹앱입니다.
텍스트와 **음성 메시지**를 주고받을 수 있고, 마음에 안 들면 "다음 상대"로 넘어갑니다.

> **데모:** https://ikdd7.github.io/Test2/ (GitHub Pages 자동 배포)

## ✨ 특징

- **회원가입 불필요** — 닉네임만(비우면 '익명') 입력하고 바로 매칭
- **1:1 랜덤 매칭** — 별도 서버 없이 공개 MQTT 브로커(WebSocket) 위에서 로비/핸드셰이크로 낯선 상대와 연결
- **음성 메시지** — 브라우저 MediaRecorder로 녹음 → 전송 → 재생
- **다음 상대** — 한 번의 탭으로 새 상대와 다시 매칭
- **입력 중 표시 · 알림음 · 이모지 · 자동 아바타**
- **관리자 전용 접속자 수** — `?admin=KEY` 로 접속한 사람만 실시간 온라인/대기/대화 수를 보는 배지
- **세련된 UI** — 글래스모피즘 다크 테마, 매칭 레이더 애니메이션, 모바일 반응형

## 🧠 매칭 동작 방식 (서버리스)

1. 매칭을 누르면 **로비 토픽**(`ripple-chat/v2/lobby`)에 "대기 중"을 주기적으로 알림
2. 대기자 중 **가장 작은 id**를 후보로 골라, **id가 작은 쪽이 초대**를 보냄 (쌍마다 초대자 1명 보장)
3. 상대가 수락하면 둘만의 **페어 토픽**(`.../p/{room}`)에서 1:1 대화
4. busy/timeout/cancel 핸드셰이크로 경쟁 상황을 정리

## 🛠 기술 스택

- 순수 **HTML / CSS / JavaScript** (빌드 없음, 정적 사이트)
- 실시간 통신: **MQTT over WebSocket** ([MQTT.js](https://github.com/mqttjs/MQTT.js))
- 공개 브로커: `wss://broker.emqx.io:8084/mqtt`
- QR 코드: api.qrserver.com (공유 모달에서 브라우저가 직접 호출)

## 🔒 개인정보 / 보안 참고

- 메시지·음성은 **어떤 서버에도 저장되지 않습니다.** 실시간 전달만 됩니다.
- 공개 브로커를 사용하므로 **민감한 정보는 보내지 마세요.**
- 텍스트는 XSS 방지를 위해 escape 후 렌더링됩니다.
- 관리자 키는 클라이언트 코드에 있으므로 **완벽한 비밀이 아닙니다.** 가벼운 차단 용도이며, 운영 시 `app.js`의 `ADMIN_KEY`를 바꾸세요.

## 🚀 로컬 실행

```bash
python3 -m http.server 8000   # http://localhost:8000
```
> 음성 녹음(getUserMedia)은 `https` 또는 `localhost`에서만 동작합니다.
